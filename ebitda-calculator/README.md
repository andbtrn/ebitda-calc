# Калькулятор мотивации по EBITDA

Веб-приложение для расчёта и управления системой мотивации руководителя на основе показателей EBITDA.

## Возможности

- ✅ Настройка параметров мотивационной схемы (версионирование)
- ✅ Ввод EBITDA по месяцам с автоматическим расчётом бонусов
- ✅ Система «банка» — отложенные выплаты
- ✅ Квартальные и годовые выплаты с проверкой условий
- ✅ Идемпотентность выплат (защита от повторов)
- ✅ Блокировка месяцев и закрытие года
- ✅ Аудит всех операций
- ✅ Русский интерфейс

## Технологии

- **Frontend**: React + TypeScript + Vite
- **Backend**: Supabase (PostgreSQL + Auth + RLS)
- **Стиль**: Notion-like минимализм

## Быстрый старт

### 1. Клонирование

```bash
cd /Users/andbtrn/Cursor/ebitda-calculator
```

### 2. Установка зависимостей

```bash
cd web
npm install
```

### 3. Настройка Supabase

Убедитесь, что файл `.env` существует и содержит:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key
```

### 4. Запуск

```bash
npm run dev
```

Откройте http://localhost:5173

## Тестовые сценарии

### 1. Регистрация и вход
- Открыть приложение → нажать «Регистрация»
- Ввести email и пароль → зарегистрироваться
- Войти с теми же данными
- **Ожидание**: пользователь авторизован, показывается форма создания организации

### 2. Создание организации
- Ввести название организации → нажать «Создать»
- **Ожидание**: организация создана, переход на главную страницу

### 3. Инициализация года
- На странице «Сводка» нажать «Инициализировать 2026 год»
- **Ожидание**: создаются 12 месяцев, 4 квартала, показываются KPI-карточки

### 4. Ввод EBITDA
- Перейти на «Месячные расчёты»
- Кликнуть на ячейку EBITDA января → ввести `1000000` → Enter
- **Ожидание**: месяц пересчитан, показаны retention, growth, bonus

### 5. Проверка расчётов
- Ввести EBITDA = 1 000 000 ₽ (выше порога 916 667 ₽)
- **Ожидание**:
  - Удержание: 80 000 ₽ (максимум)
  - Рост: (1 000 000 - 916 667) × 0.25 = 20 833 ₽
  - Бонус: 100 833 ₽
  - Сейчас: 50 417 ₽ (50%)
  - В банк: 50 416 ₽ (50%)

### 6. Накопление банка
- Заполнить январь, февраль, март
- **Ожидание**: банк накапливается, баланс растёт

### 7. Квартальная выплата
- Перейти на «Банк и выплаты»
- Заполнить все 3 месяца Q1 (условие должно выполниться)
- Нажать «Выплатить» у Q1
- **Ожидание**: выплата выполнена, баланс уменьшился

### 8. Попытка повторной выплаты
- Попробовать нажать «Выплатить» для Q1 ещё раз
- **Ожидание**: ошибка «Выплата за Q1 уже выполнена»

### 9. Блокировка месяца
- На «Месячные расчёты» нажать 🔓 у января
- Попробовать изменить EBITDA января
- **Ожидание**: редактирование заблокировано

### 10. Закрытие года
- Заполнить все 12 месяцев
- Перейти на «Банк и выплаты» → «Закрыть год»
- Подтвердить
- **Ожидание**: год закрыт, все месяцы заблокированы

### 11. Смена конфигурации
- Перейти на «Настройки»
- Изменить «Ставку роста» → «Создать новую версию»
- **Ожидание**: версия создана, расчёты пересчитаны

### 12. Ручная корректировка банка
- На «Банк и выплаты» нажать «Ручная корректировка»
- Ввести сумму и комментарий
- **Ожидание**: корректировка применена, запись в журнале

## Формулы расчёта

### Удержание (retention)
```
если EBITDA < monthly_base: 0
если EBITDA в [base, threshold]: retention_max × (EBITDA - base) / (threshold - base)
если EBITDA > threshold: retention_max
```

### Рост (growth)
```
growth = growth_rate × max(0, EBITDA - threshold)
```

### Распределение
```
total_bonus = retention + growth
paid_now = total_bonus × (1 - bank_split_pct)
to_bank = total_bonus × bank_split_pct
```
